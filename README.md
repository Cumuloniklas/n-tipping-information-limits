# On the Information Limits of Local Early-Warning Indicators for Noise-Induced Tipping

This repository contains a concise mathematical note proving an explicit non-identifiability theorem for local prediction functionals of noise-induced escape in one-dimensional gradient diffusions.

## Abstract
We construct two explicit $C^\infty(\mathbb{R})$ potentials $V_1, V_2$ that coincide identically on an open neighborhood $U = (-\infty, -0.5)$ of the stable equilibrium $x_m = -1$, yet exhibit distinct asymptotic exit-rate exponents $\lim_{D\to 0} D\log h_i(D) = -\Delta V_i$ ($\Delta V_1 = 1/4$, $\Delta V_2 = 3/4$), where $h_i(D) = 1/\mathbb{E}_{-1}[\tau_i]$. Consequently, no functional depending solely on $V|_U$ and $D$ can determine the asymptotic escape exponent for both systems. We also contrast this with the real-analytic case and state an algebraic barrier-accuracy corollary under a known prefactor.
